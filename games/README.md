# Your games

Put each game in a folder of its own here, for example `games/tavla-plus/`. The simulator lists every folder in
`games/` and `examples/` that has a `game.json`.

The quickest start is to copy an example: `examples/xox` for a table game, `examples/ari` for a solo game.
Then change the `id` and `name` in `game.json`. See the kit's README.md for the rest.
